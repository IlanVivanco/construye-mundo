# Design system

The site's visual standard: what new pages follow and what client designs are compared against. Hand-written from
the generated design inventory (`<inventory>.md`), which lists every value the site defines, stores, and renders.
Each value below names where it lives: kit global, theme option, CSS file, or hardcoded.

## Foundations

- **Colors**: role of each color (page background, text, muted text, accents, buttons, cards, borders).
- **Fonts**: the typeface, its weights, and the one family name to use for each weight.
- **Type scale**: H1–H4, eyebrows, body, lede, captions: preset or size, weight, line height, per breakpoint.
- **Layout**: content width, section padding (per breakpoint), gaps; the container settings that produce them.
- **Breakpoints**: the active ones and the widths pages must be checked at.

## Components

- **Buttons**: border, radius, padding (per breakpoint), weight, primary and secondary, hover and focus states.
- **Cards**: background, border, radius, padding.
- **Highlights**: how highlighted words are marked up and colored.
- **Forms**: field and button styling for embedded forms.
- **Header and footer**: templates, and page-level exceptions.
